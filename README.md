# Darlene Otadoy Portfolio 2025

My personal portfolio website showcasing my projects, skills, and journey as a first-year BS IT student at University of San Carlos.

## How to View My Portfolio

### Step 1: Install Dependencies

Open a terminal in this folder and run:

```bash
npm install
```

### Step 2: Start the Development Server

Run the following command:

```bash
npm run dev
```

### Step 3: Open in Browser

Once the server starts, open your web browser and go to:

```
http://localhost:3000
```

That's it! The portfolio should now be visible in your browser.

## Troubleshooting

- **Port already in use?** Try `npm run dev -- -p 3001` to use a different port
- **Dependencies error?** Delete `node_modules` folder and run `npm install` again
- **Changes not showing?** Hard refresh your browser with `Ctrl + Shift + R` (Windows) or `Cmd + Shift + R` (Mac)

## Build for Production

To create an optimized production build:

```bash
npm run build
npm start
```
